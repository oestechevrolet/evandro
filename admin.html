Abrir o site público ↗

1Conexão com o GitHub

Feito uma única vez neste computador/celular. Os dados ficam salvos só neste navegador.

Nunca compartilhe este token. Ele só dá acesso a este repositório.
Como gerar o token
  1. No GitHub, clique na sua foto → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Em Repository access, escolha Only select repositories e marque só o repositório do site.
  3. Em Permissions → Repository permissions → Contents, escolha Read and write.
  4. Gere, copie e cole aqui. Defina uma validade (ex.: 1 ano) e gere outro quando vencer.

2Enviar a planilha de estoque

Exporte o estoque no DMS e arraste o arquivo aqui (CSV ou Excel). Preço, nome de quem reservou, pedido de fábrica e dias de estoque não vão para o site — só o que o cliente pode ver.
